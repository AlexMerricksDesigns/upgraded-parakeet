# Alex Merricks Designs website

Portfolio, online store, and business home for bringing together design work,
products, writing, and experiments into one public website.

This repository is intentionally starting simple. The goal is to make it easy to
sketch ideas quickly, turn the best ones into pages/products, and keep the site
deployable as it grows.

## Current status

- Repository connected to GitHub
- Project workflow documented
- Website framework still to be chosen/scaffolded

## Useful docs

- [Project workflow](docs/workflow.md): the simple Git/GitHub routine for working
  from mobile, laptop, PC, or a cloud agent.

## Near-term direction

The first practical milestone is a starter website with:

- Home page
- About/story page
- Work/portfolio page
- Shop/products page
- Journal/updates page
- Contact/enquiry path

The site can begin with placeholder content and local editable files, then later
connect to checkout, analytics, newsletter, and a fuller store system.
