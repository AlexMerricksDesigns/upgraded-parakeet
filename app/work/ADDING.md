# Adding and editing work content

**Catalog workflow:** [`EDITOR.md`](../../EDITOR.md) · [`data/README.md`](../../data/README.md) · `npm run content:sync`

Route groups like `(categories)` do not appear in URLs.

## Where things live

| Live URL | Edit (source) | Then run |
|----------|---------------|----------|
| `/work/photography/series/<slug>` | `data/series.csv` + optional `content/work/series/<slug>.js` | `npm run content:sync` |
| `/work/photography/captured/<slug>` | `data/photographs.csv`, `data/assets.csv` | `content:sync` |
| `/work/<cat>/products/<slug>` | `data/products.csv`, `data/product_items.csv` + optional `content/work/products/<slug>.js` | `content:sync` |
| `/work/<cat>/journal/<slug>` | `data/journal.csv` + `content/journal/posts/<slug>.js` | `content:sync` |
| `/work/<cat>/projects/<slug>` | `categories-data.base.js`, `manifest.json`, `content/work/projects/<slug>.js` | — |
| `/work/photography` hub | `components/work/hub/photography/` | — |

**Do not hand-edit:** `photography-manifest.json`, `categories-data.generated.js`, `content/catalog/*.json` (generated by sync).

## Add photographs (bulk)

1. Add rows to [`data/photographs.csv`](../../data/photographs.csv) — see [`data/README.md`](../../data/README.md).
2. Add asset rows to [`data/assets.csv`](../../data/assets.csv) if needed.
3. `npm run content:sync`
4. `npm run catalog:import-csv` → `npm run assets:ingest` → `npm run assets:optimize` (when adding files)
5. Optional rich copy: [`content/overrides/photographs/<slug>.md`](../../content/overrides/photographs/) or legacy `content/work/captured/<slug>.js`

## Add a series

1. Row in `data/series.csv`
2. `npm run content:sync`
3. Optional narrative: `content/work/series/<slug>.js`

## Add a product / bundle

1. Row in `data/products.csv`
2. Bundle members in `data/product_items.csv`
3. `npm run content:sync`
4. Optional shelf sections: `content/work/products/<slug>.js`

## Add a journal post

1. Row in `data/journal.csv` (card metadata)
2. `content/journal/posts/<slug>.js` (body)
3. `journalSlugs` in [`categories-data.base.js`](categories-data.base.js) subsection
4. `npm run content:sync`

## Add a craft project (non-catalog)

1. [`categories-data.base.js`](categories-data.base.js) — subsection `slugs`
2. [`manifest.json`](manifest.json) — card metadata
3. [`content/work/projects/<slug>.js`](../../content/work/projects/)
4. Images → `npm run assets:optimize`
